// ==UserScript==
// @name         VideoSync
// @namespace    https://github.com/qwreey/videosync
// @version      0.1.0
// @description  Watch the same video together on your own accounts. Only the URL, position, play state and chat cross the wire — never the video itself.
// @author       qwreey
// @license      MIT
// @match-providers
// @grant        GM_getValue
// @grant        GM_setValue
// @grant        GM_xmlhttpRequest
// @grant        GM_openInTab
// @grant        GM_registerMenuCommand
// @connect      *
// @run-at       document-idle
// @noframes
// ==/UserScript==
//
// The @match lines are generated from the built-in provider descriptors
// (providers/*.json). To use a site you added yourself (menu -> "제공자 설명
// 추가"), add its @match line here as well: a userscript cannot add sites to
// itself. The menu tells you the exact line. The script has no per-site code:
// a descriptor is data it reads.
//
// @grant is NOT optional and not only for storage. With `@grant none` a
// userscript is injected into the PAGE context, where the site's
// Content-Security-Policy governs everything it does -- including opening a
// WebSocket. Most OTT sites ship a `connect-src` that does not list your
// self-hosted server, so the socket would simply be refused. Granting any GM
// API moves the script into the userscript sandbox, which has its own CSP.
//
// GM_xmlhttpRequest carries every HTTP call to your server -- room creation,
// sign-in, tickets -- from Tampermonkey's background, where the page's CSP and
// CORS do not apply and your sign-in token stays out of the page. The server is
// yours to choose, so it cannot be named here: `@connect *` makes Tampermonkey
// ask you once per server before the first call.
//
// @noframes because an embedded player in an iframe would otherwise mount a
// second panel and a second member for the same person.
